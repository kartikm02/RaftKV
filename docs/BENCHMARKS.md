# Measurements

No throughput, latency, failover, durability, chaos, or AWS performance results have been measured. Election simulation tests are functional tests, not evidence of real-cluster performance. Do not put projected AWS figures on a resume as measured results. When a real cluster exists, record the raw observations, hardware, JVM, disk, fsync setting, workload, repetitions and percentile method here. An AWS estimate needs a specific instance, storage, topology and workload and must be explicitly labeled unvalidated; local machine numbers do not establish an AWS equivalent.
