# Simulation

Run `./gradlew sim -PsimArgs="--seed=42 --duration=1000"`. Reusing the seed and duration produces the same trace. Time is virtual milliseconds. The queue is ordered by timestamp then insertion sequence. The simulator supports seeded loss, duplication, delivery delay and isolating nodes through its Java API. In-flight messages are discarded on delivery if their source or destination is isolated. The CLI currently exposes seed and duration only.

Tests run 1,000 healthy three-node election scenarios and 1,000 scenarios with isolation, 20% loss and 25% duplication followed by healing. After every event the model checks at most one observed leader per term; tests assert one current leader after the stated healthy period. Reproducibility is checked with and without injected faults. This model has no log or storage integration, crash/restart, asymmetric partitions, disk faults, client workload, linearizability checker, or real network. Passing these tests does not establish the correctness of Raft under failures.
